Fix 10-Digit Phone Number Crash in models.py

A standard MySQL Integer maxes out at 2,147,483,647. Use BigInteger so 10-digit numbers like 8940319212 don't crash the server on POST or PUT: 

from sqlalchemy import Column, Integer, String, BigInteger
from database import Base

class User(Base):
    __tablename__ = "cloths"
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)
    phno = Column(BigInteger, unique=True, nullable=False) # <-- Changed to BigInteger

*Remember to run DROP TABLE cloths; in MySQL Workbench/CLI and restart Uvicorn so SQLAlchemy recreates the table with BIGINT.

Return User id in GET /users (main.py)

In main.py, change response_model=list[UserCreate] to response_model=list[UserResponse] and rename the first get_user function to get_users so every card includes its real database id: 

@app.get("/users", response_model=list[UserResponse])
def get_users(db: Session = Depends(get_db)):
    return db.query(User).all()
